# 教师工具箱 —— 功能清单

> 定位:面向初中化学老师日常备课/教学场景的 Windows 桌面小工具集合
> 技术方向:Electron + Vue3 + TS(界面) + Python 打包 exe(核心处理逻辑)

---

## 一、图片/文档处理类(高频刚需)

| 功能 | 说明 | 优先级 | 技术要点 |
|---|---|---|---|
| 图片去水印 | 批量清除下载课件/习题图片上的水印 | ⭐⭐⭐ | OpenCV / lama-cleaner (inpainting) |
| 图片转文字/公式识别(OCR) | 拍照的化学方程式、结构式转文字或 LaTeX | ⭐⭐⭐ | PaddleOCR(中文+公式效果较好) |
| PDF 转 Word | 教辅 PDF 转可编辑文档,方便二次修改出题 | ⭐⭐⭐ | PyMuPDF / pdfplumber |
| PDF 合并/拆分 | 多份试卷、讲义合并成一份或按章节拆分 | ⭐⭐ | PyMuPDF |
| 扫描件校正 | 手机拍的试卷去黑边、纠偏、增强对比度 | ⭐⭐ | OpenCV |
| 图片批量压缩/格式转换 | 课件配图统一压缩,减小 PPT 体积 | ⭐ | Pillow |

## 二、批量/重复劳动类

| 功能 | 说明 | 优先级 | 技术要点 |
|---|---|---|---|
| 文件批量重命名 | 按班级/学号/考试名称规则批量重命名试卷、作业照片 | ⭐⭐⭐ | Python os/pathlib |
| 文件按班级/学号自动归类 | 拍照上传后自动分文件夹 | ⭐⭐ | 结合 OCR 识别学号/姓名 |
| Word/Excel 模板批量填充 | 成绩单、家长会通知等批量生成 | ⭐⭐ | python-docx / openpyxl |

## 三、成绩与数据统计类

| 功能 | 说明 | 优先级 | 技术要点 |
|---|---|---|---|
| 成绩单自动统计 | 导入 Excel 原始分数,自动出年级/班级排名、分数段分布 | ⭐⭐⭐ | pandas + openpyxl |
| 成绩趋势图表 | 生成班级/个人历次考试趋势折线图,插入报告 | ⭐⭐ | pandas + matplotlib |
| 试题正确率分析 | 按题号统计全班/全年级正确率,定位薄弱知识点 | ⭐ | pandas |

## 四、化学学科专用小工具(差异化,别人做不到的贴心功能)

| 功能 | 说明 | 优先级 | 技术要点 |
|---|---|---|---|
| 化学方程式配平助手 | 输入反应物/生成物,自动配平系数 | ⭐⭐ | 纯 Python 算法(矩阵法配平) |
| 元素周期表速查 | 内嵌可搜索的元素周期表,点击查详情 | ⭐ | 纯前端(Vue),静态数据即可 |
| 分子结构图快速插入 | 常见分子结构图库,拖拽插入课件 | ⭐ | 结合已有课件生成工具 |
| 实验安全须知/步骤清单生成 | 按实验类型自动生成规范步骤和注意事项 | ⭐ | 模板 + 简单规则引擎 |

## 五、课件生成类(与现有项目整合)

| 功能 | 说明 | 优先级 | 备注 |
|---|---|---|---|
| 说课/课件 PPT 生成 | 已有单独项目规划(教师课件生成工具),后续可作为工具箱一个入口 | ⭐⭐⭐ | 复用现有 PRD 方案 |
| 化学方程式/结构图自动插入课件 | 生成课件时自动匹配插入对应学科素材 | ⭐ | 依赖上面结构图库 |

---

## 建议的第一期 MVP(先做能立刻用上的)

1. **图片去水印**
2. **PDF 转 Word**
3. **OCR 文字/公式识别**
4. **文件批量重命名**

这四个功能场景明确、技术风险低(都有现成 Python 库)、每周都会用到,适合作为工具箱的第一个可发布版本,界面上做成"拖文件进来 → 选功能 → 出结果"的统一交互模式,后续再逐步加成绩统计、化学专用工具等模块。
